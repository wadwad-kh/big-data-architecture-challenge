# Big Data Engineering Architecture Challenge: Pulse-Scale

This repository contains the architecture design and deliverables for the SE446 Architecture Challenge.

## Deliverables
- **D1:** Architecture Diagram
- **D2:** Technology Choices
- **D3:** Data Model and Partitioning
- **D4:** Three Optimization Decisions
- **D5:** Failure Modes
- **D6:** Cost Back-of-Envelope
- **Bonus:** Contradictions, Multi-region DR, Schema Evolution

*Designed for high throughput (50k articles/min), sub-30-second latency, and strict $40,000/month budget constraint.*
